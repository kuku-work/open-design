# 怎麼寫定位矩陣、SWOT、產品切角

給 agent 的寫作指引。這三節都是「圖表 ＋ 值」，**圖表由生成器畫，值由你填**。

---

## 一、定位矩陣

雙軸四象限＋競品座標。**軸怎麼定，決定整張圖有沒有用。**

```yaml
positioning_matrix:
  axis_v: {tag: 產品功能, top: 一般功能, bottom: 差異化功能}
  axis_h: {tag: 品牌發展, left: 主力品項, right: 輔推品項}
  quadrants:
    tl: [品牌調性鮮明且知名度高, 款式多樣、選擇性多元]
    tr: [以滿足基本使用需求為主, 有主推款式、整體樣式少]
    bl: [產品具有獨創研發技術, 手機掛繩為明星產品]
    br: [具有獨特賣點或特色, 賣場多分類為周邊配件]
  competitors:
    - {name: CASETiFY, x: -0.12, y: 0.30}
    - {name: bitplay,  x: -0.26, y: -0.30}
  own: {x: 0.28, y: -0.32}
```

**軸的選法**：兩軸要**互相獨立**，而且**你自己要落在有話可說的象限**。
如果所有競品都擠在同一格，那是軸選錯了——換一組軸重畫。

**座標怎麼給**：`x` / `y` 都是 **-1 到 1**，(0,0) 是原點。
生成器會換算成版面位置，你不用管 pt。⚠️ 座標是**判斷**不是量測——
它代表「我們認為這個品牌在這個維度的相對位置」，需要和需求方對過才算數。

**四象限的描述**寫的是「落在這一格的品牌有什麼共同特徵」，不是點評個別競品。
每格 2 條最常見。

## 二、SWOT

四格是框架（固定），條目是內容（你填）。

```yaml
swot:
  strengths: [繩索加長型 7.5mm 掛片, 可掛繩設計適配多場景]
  weaknesses: [繩索寬度僅 6mm 一種尺寸、5 色供挑選, 售價相對偏高]
  opportunities: []
  threats: []
```

**兩條紀律**：

1. **優勢／劣勢要帶具體數字或規格**，不要形容詞。
   ✅「繩索加長型 7.5mm 掛片」「售價相對偏高」
   ❌「品質優良」「價格有競爭力」← 這種寫法對誰都成立，等於沒寫

2. **機會／威脅講的是外部環境，不是自己**。
   ✅「競品條款限制通路鋪貨」「掛繩品類搜尋量年增」
   ❌「我們可以擴大產品線」← 那是策略不是機會

填不出來就留空陣列，生成器畫三個空槽——**空著看得出還缺什麼，編出來就看不出了**。

## 三、產品切角

一個提案一頁，加一頁 Recap 表。**提案數不寫死**，給幾個出幾頁。

```yaml
pitches:
  - headline: 自帶氣場，內外兼具        # 主標語：一句 slogan
    product_name: STRAP Pure 專屬香氛手機掛繩   # 產品命名：這個切角下叫什麼
    subtitle: null                    # 副標：一句補充
    concept: null                     # CONCEPT：3–4 句概念介紹
```

**三個切角要是三個方向，不是三種說法。**
寫完把三個 `product_name` 並排——如果只是換形容詞（專屬／行動／編織），
那是同一個切角的三次改寫；真正的切角差異會讓**產品命名的名詞**不同
（掛繩／背繩／擴香），因為它們訴求的使用情境不同。

**主標語的檢查**：把產品名遮掉，這句話還說得出是在講什麼嗎？
說不出來就太空泛。

## 四、市場溝通主軸

`communication_axes` 是核心概念清單，**數量決定文氏圖幾個圓**：

```yaml
communication_axes: [個人風采, 風格態度, 駕馭自如]
```

- 1 個 → 單圓置中
- 2 個 → 左右並列
- 3 個 → 上一下二（標準三圓交集）
- 4 個 → 田字排列
- 5 個以上 → 環狀均分

生成器算圓心座標，你只給概念。

**選概念的判準**：三個概念要能**互相交集**才適合用文氏圖。
如果三者是並列的功能清單（防水／輕量／耐摔），那不是文氏圖，
是三欄特色——改用產品規格節的三欄版式。
